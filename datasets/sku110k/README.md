# SKU-110K Dataset (Shelf Product Detection & Retail Shelf Analytics)
Location: `datasets/sku110k/`

## Purpose:
- Dense shelf product detection
- Retail shelf analytics and planogram alignment
- Bounding box annotations for tightly packed retail items

## Directory Structure:
- `images/` - Training, validation, and test shelf images
- `annotations/` - Bounding box annotations in CSV format (`image_name,x1,y1,x2,y2,class,image_width,image_height`)
