# COCO Dataset (Person Detection & Multi-Object Tracking)
Location: `datasets/coco/`

## Purpose:
- Person detection (`class === 'person'`)
- Multi-object tracking and bounding box localization
- Baseline validation for YOLOv8 and MobileNet-v2 models

## Directory Structure:
- `images/` - Training and validation video frame images
- `annotations/` - COCO format JSON annotations (`instances_val2017.json`)
